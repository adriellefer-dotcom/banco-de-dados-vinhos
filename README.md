# Banco de Dados de Vinhos

Projeto acadêmico desenvolvido em MySQL para criação e gerenciamento de um banco de dados relacionado a vinhos, vinícolas e regiões produtoras.

## 📌 Sobre o projeto

O Banco de Dados de Vinhos foi desenvolvido como atividade acadêmica com o objetivo de aplicar conceitos de modelagem e gerenciamento de bancos de dados relacionais.

O projeto organiza informações sobre regiões, vinícolas e vinhos, estabelecendo relacionamentos entre as entidades e permitindo a realização de consultas utilizando SQL.

Também foram trabalhados conceitos relacionados à criação de usuários, concessão de permissões e controle de acesso aos dados.

## 🚀 Funcionalidades

- Criação do banco de dados
- Criação de tabelas relacionais
- Cadastro de regiões
- Cadastro de vinícolas
- Cadastro de vinhos
- Definição de chaves primárias
- Definição de chaves estrangeiras
- Relacionamento entre tabelas
- Inserção de dados
- Consultas utilizando SQL
- Utilização de JOIN entre tabelas
- Criação de usuário para acesso ao banco
- Concessão de permissões específicas
- Configuração de limite de consultas

## 🛠️ Tecnologias utilizadas

- MySQL
- SQL
- Banco de dados relacional

## 🗃️ Estrutura do banco

O banco de dados é composto pelas principais entidades:

- `Regiao` — informações das regiões produtoras
- `Vinicola` — informações das vinícolas
- `Vinho` — informações dos vinhos

As tabelas são relacionadas por meio de chaves primárias e estrangeiras.

O projeto também apresenta uma consulta utilizando `JOIN` para relacionar informações de vinhos, vinícolas e regiões.

## 🔐 Controle de acesso

O projeto também trabalha conceitos de gerenciamento de usuários e permissões no MySQL.

Para a versão disponibilizada neste repositório público, credenciais reais não são utilizadas no código.

## 🎓 Contexto acadêmico

Este projeto foi desenvolvido como parte do processo de aprendizagem em banco de dados durante a formação em Análise e Desenvolvimento de Sistemas.

A atividade possibilitou trabalhar conceitos de bancos relacionais e compreender como estruturar, relacionar e consultar informações utilizando SQL.
